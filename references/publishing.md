# 可配置的发布流程

发布方式不写死在 Skill 中。账号、平台、密钥都是每次任务的配置，不进入 Skill 文件或交付文件。

## 一、读取发布配置的优先级

1. 用户在本次任务或 `templates/task-brief.md` 中明确指定的平台 / 已有站点。
2. 工作目录或用户级配置中的发布配置（如发布配置文件、环境变量、已登录的托管 CLI）。
3. 当前已配置、已登录且适合的静态网页托管服务。
4. 以上皆无：先完成本地成品，再集中说明需要用户完成的最少登录或连接步骤，不擅自替用户注册或购买。

约束：不擅自购买服务或域名；不暴露账号密钥；每篇文章使用独立地址，避免覆盖其他文章。

## 二、选择托管的决策

- 优先长期托管地址（自有站点、已登录的静态托管 / Pages）。
- 用户未指定长期平台、也没有已配置托管时：默认走内置的匿名免账号 72h 路线（见第六节），无需注册、无需密钥。
- 采用匿名临时路线时必须向用户注明：保留时长（默认 72h = 3 天）、到期自动失效、无法自行删除、内容可能被缓存或索引。
- 使用前必须实测，不假设某平台可用：能否连通；上传后是否以 `text/html` 渲染（而非下载页或查看器）；单文件大小限制。匿名文件床的可达性随网络与时间变化（可能被间歇性封锁），每次运行都重新探测。
- 探测顺序建议：先小探针文件确认渲染行为，再上传正式文件；上传后校验服务端副本与本地一致（字节数 / 哈希）。

## 三、只发布这些

- 最终 HTML 与必要公开资源（内嵌图片的独立 HTML 通常只需一个文件）。

禁止发布：原始音频、逐字稿、作者风格报告、用户私人感受、内部核对记录、账号配置。

## 四、公开链接标准

必须满足：
- 使用 HTTP 或 HTTPS。
- 其他人无需登录作者账号即可阅读。
- 不依赖用户电脑持续开机。
- 不使用 localhost、127.0.0.1、局域网地址、本地文件路径或管理后台地址冒充公开链接。

优先长期托管地址；临时链接必须注明限制（保留时长、不可删除等）。

## 五、发布后验证

- 在未登录状态访问公开链接。
- 确认正文、图片正常显示（实测渲染，而非仅看 HTTP 状态码）。
- 确认没有公开私人材料。
- 记录实际验证结果；未验证的项目如实说明，不声称全部通过。

## 六、默认匿名临时路线（无需账号，3 天有效）

用户未指定长期平台时的默认发布路线。已实测可用：上传后返回直链，访问时 `Content-Type: text/html`，任何人免登录打开即渲染为网页。

- 端点：`https://litterbox.catbox.moe/resources/internals/api.php`
- 方法：POST multipart/form-data
- 字段：`reqtype=fileupload`、`time=72h`（可选 1h/12h/24h/72h）、文件字段名 `fileToUpload`
- 返回：响应体即公开 URL（纯文本）
- 保留：72h（3 天）后自动删除；匿名上传**无法自行删除**；内容可能被缓存或索引
- 上传文件名用 ASCII（非 ASCII 文件名在 multipart 中易出错）

配套脚本：`scripts/publish_anonymous.py`

```
python scripts/publish_anonymous.py article.html            # 默认 72h
python scripts/publish_anonymous.py article.html --expire 24h
python scripts/publish_anonymous.py article.html --name my-slug.html --retries 6
```

脚本行为：自动把文件名转成 ASCII slug；每次重试新建会话并带 `Connection: close`、指数退避（该网络会间歇性掐断 TLS）；上传成功后回读公开链接，校验 HTTP 200、`Content-Type` 含 `text/html`、字节数与 md5 与本地一致；stdout 为逐行可读日志，成功打印 `SUCCESS <url>`，失败退出码 1 且不抛堆栈。

已知限制与处置：
- catbox / litterbox 域名在部分网络下会被**间歇性封锁**（表现为 TLS 中途 EOF 或读超时，读写皆失败），过一段时间又恢复。这是网络层现象，不是脚本错误。
- 连续多次重试仍失败时：不要无限重试；告知用户当前网络窗口不可达，稍后重试，或改走已配置的长期托管 / 请用户指定平台。
- 同一网络下曾实测可用的其他匿名源均不稳定或不渲染 HTML（如 0x0.st 关闭上传、pixeldrain/tmpfiles 连不上、uguu 拒收 .html、gofile 只给下载页），不要把它们当作可靠备选；如要新增备选，先按第二节实测。
