# 真实配图要求

数量：约 3–5 张，服从内容需要。找不到合适图片时减少数量或请求用户补充；不用不相关图片凑数，也不擅自改成生成图。

## 可选图片来源

- 与正文对应的真实人物、活动、地点或物品照片。
- 官方产品照片。
- 确有解释作用的原始文档、网页或公开资料截图。
- 用户提供且可用于公开发布的真实图片。

## 具体要求

1. 实际查看每张图片，确认人物、事件、时间背景与正文相符；不能只根据搜索标题选图。
2. 优先采用使用条件明确、允许本次公开使用的图片，例如合适授权的开放图片、官方明确允许使用的媒体素材。
3. "来自官网"或"注明来源"不自动代表可以任意转载；记录实际使用依据。
4. 每张图保存：来源页、作者或机构、授权说明、图注。统一写入 `sources.md`。
5. 图注只写可确认的信息。资料照注明"资料照"，不能让读者误以为是文中某次具体会面的现场照。
6. 不使用 AI 生成图片、SVG 示意图、虚构截图或占位图代替真实配图。
7. 图片尽量保存到本地 `images/`，避免使用失效风险高的外链。
8. 用于内嵌 HTML 时，将图片以 base64 内嵌以保证断网可读；同时保留 `images/` 原图文件。
