# 任务输入模板（task-brief）

复制本模板填写；缺失项留空并标注"缺"。填好后连同音频与风格报告一起提供。

## 必需

- 播客音频文件：（本地路径或可下载链接）
- 作者风格报告：（本地路径，JSON / Markdown / TXT；已总结好，无需重新分析）

## 可选

- 我真正想分享的观点 / 感受 / 印象深刻的片段：
- 指定文章角度：（不填则由成稿方自选有材料支撑的角度）
- 目标读者：
- 字数：（默认 2500–3500）
- 我提供的真实图片：（路径，可多张；需可用于公开发布）
- 发布平台或已有站点：（不填则按发布配置优先级自动选择）
- 是否发布：（默认：成稿并检查后发布；填"仅本地"则不发布）
- 是否先看提纲：（默认否，自动完成选角度→提纲→正文）

## 授权确认

- 是否允许将音频上传到外部转写服务：是 / 否（服务：____ 费用：____）
- 是否允许发布到公网：是 / 否
- 是否接受临时链接的限制（到期失效、不可删除）：是 / 否（仅当无长期托管时相关）
